# Relatórios reais do NIVON
1. Consulte dados atuais das pipelines autorizadas, nunca documentos simulados nem valores copiados de testes.
2. Separe páginas Agricultura e Pecuária. Data/hora de corte, fonte, competência, natureza do indicador e último período validado são obrigatórios.
3. Use PageIndex como **apoio documental**, nunca como substituto da base de séries. Se o texto gerado divergir de uma tabela observada, marque o conflito.
4. Distinga OBSERVADO/DECLARADO, ESTIMADO, PROJETADO, INFERIDO e SOURCE_LAG; não chamar line-up programado de realizado.
5. Pare a publicação quando faltar referência ou evidência essencial; registre a lacuna em vez de inventar dados.
