# NIVON — Identidade visual agro (v0.2)

**Estado:** direção criativa aprovada em 21/10/2026. Estes arquivos são uma **primeira reconstrução vetorial** inspirada na proposta visual aprovada em conversa, não uma vetorização idêntica dos pixels do painel gerado por IA. Ativos técnicos ainda em revisão; não implicam registro de marca ou liberação comercial.

## Conceito

A marca cruza **agronegócio + inteligência de dados + logística**. O `N` estilizado remete a talhões, curvas de nível, linhas de plantio e movimento de informações, sem restringir o NIVON a uma cultura agrícola. O nome deve aparecer como **NIVON** em caixa alta na versão institucional.

**Assinatura proposta (a validar editorialmente):** “Inteligência para mover o agro.”

Inter não está incluída neste repositório.

## Regras de aplicação

1. Priorizar o verde profundo como cor de base; usar o dourado safra com parcimônia.
2. Preservar área de respiro em torno da marca de ao menos 1/2 da altura do símbolo.
3. Evitar efeitos 3D, distorção, contorno decorativo e contraste insuficiente.
4. Indicadores de alta/baixa em relatórios devem manter semântica própria e não depender só da paleta institucional.
5. Para o **IVO**, desenvolver uma submarca correlata antes de utilizar o N do NIVON como identidade do assistente.
6. Não inserir `®` ou `™` automaticamente, nem contatos/domínios fictícios.
7. Verificar registro de marca, semelhanças, acessibilidade e legibilidade em tamanhos pequenos antes do lançamento.

## Limitações desta versão

O **painel PNG conceitual produzido no chat** é uma imagem de referência, não foi incorporado aqui como ativo raster. Os arquivos neste diretório são reconstruções técnicas editáveis e devem passar por revisão visual frente ao conceito original. Exportações PNG, favicon final e manuais fechados ficam para a próxima revisão.

A marca não representa que o NIVON esteja operando comercialmente. O repositório público não concede licença de uso da marca ou de terceiros.
